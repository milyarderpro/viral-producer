# Viral Producer

Repository sumber untuk membangun AI content producer yang menghasilkan naskah Facebook Reels bertema trivia berbahasa Inggris.

## Tujuan

Sistem ini akan:

- mengikuti DNA editorial dari dataset referensi;
- memprioritaskan audiens US, Canada, UK, dan Australia;
- memverifikasi fakta sebelum digunakan;
- mencegah duplikasi fakta secara semantik;
- menyimpan draft, antrean siap posting, dan arsip publikasi di GitHub.

## Status implementasi

Tahap 1 — repository initialization.

Detail workflow, struktur data, instruksi GPT, dan panduan instalasi akan ditambahkan secara bertahap pada branch implementasi.
